### ☁️ What I do

I lead the **cloud team at [Epsilon](https://github.com/epsilonline)**, an AWS Advanced Partner based in Naples.
I follow projects end to end: the first technical call, the estimate, the architecture, the code, and the go-live.

- 🏗️ **Cloud architecture on AWS:** migrations, multi-account organizations, landing zones, cost optimization
- ⎈ **Kubernetes:** cluster administration, Helm, platform engineering
- 🧱 **Infrastructure as Code:** Terraform modules for everything that can be written down
- 🔐 **DevSecOps:** CI/CD pipelines with security built in, from the first commit to the running cluster, plus hardened Kubernetes workloads
- 🛡️ **Cloud security:** threat detection, SIEM, malware scanning, compliance architectures
- 🤖 **Generative & agentic AI:** from SageMaker playgrounds to AI agents that run operations
- 🧪 **Funded R&D:** edge AI for predictive maintenance on road infrastructure, smart-water IoT platforms, indoor positioning, agentic robotics
- 🎓 **Teaching & community:** university lectures, AWS meetups and events, training DevOps teams
